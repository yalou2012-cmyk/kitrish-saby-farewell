# kitrish-saby-farewell

Персональный шуточный farewell-сайт для коллеги, оформленный как пародийный интерфейс Saby/СБИС. Это самостоятельный подарок, а не настоящий рабочий сервис: авторизации, backend и сбора пользовательских данных нет.

## Стек

- Next.js 15 (App Router)
- React 19
- TypeScript
- CSS без UI-фреймворков и тяжёлых библиотек анимации
- локальные mock data и `localStorage` для прогресса «Мысли дня»

## Запуск

```bash
pnpm install
pnpm dev
```

Открыть: `http://127.0.0.1:3000/`.

Проверка production-сборки:

```bash
pnpm build
pnpm start
```

Отдельных `lint` и `test` scripts сейчас нет.

## Структура

- `app/page.tsx` — оболочка Saby, навигация, экраны задач и документов, профиль и mock data.
- `app/ThoughtOfDay.tsx` — модальное окно «Мысль дня» и локальный прогресс.
- `app/FarewellScenario.tsx` — финальная задача и сцена с пакетами.
- `app/*.css` — стили соответствующих экранов и точечные overrides.
- `public/kitrish-profile-source.png` — локальный источник изображения профиля.
- `public/assets/thoughts/` — 12 нарезанных карточек «Мысль дня».
- `public/assets/` — ожидаемое место для других проектных изображений.

## Реализованные экраны

- «Документы»: 18 шуточных корпоративных документов, статусы и подробные карточки.
- «Задачи»: 23 гипертрофированно срочные задачи и карточка задачи.
- Финальная задача: последняя строка списка — «Создать ещё одно хорошее общее воспоминание»; после открытия запускается сцена Ozon/Wildberries.
- «Мысль дня»: случайная выдача 12 карточек, hotspot-зоны и счётчик просмотренного.
- Профиль «Китриш О.» с локальным изображением и шуточной должностью.

## Дальнейшая разработка

Перед изменениями прочитать `AGENTS.md`, `PROJECT_STATE.md`, `DECISIONS.md`, `CONTENT.md` и `BACKLOG.md`. Сначала изучить существующий экран, менять только необходимое, затем выполнить production-сборку и проверить затронутый сценарий. Крупные изменения отражать в проектной памяти.
