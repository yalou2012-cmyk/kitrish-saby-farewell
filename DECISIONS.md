# Устойчивые проектные решения

- Проект создаётся непосредственно в коде Next.js, не в Lovable.
- GitHub должен использоваться как хранилище исходников; на текущий момент remote ещё не подключён.
- Vercel будет использоваться только для публикации готовой версии.
- Визуальная основа — интерфейс Saby/СБИС, но сайт остаётся очевидной пародией и подарком.
- Ключевые интерактивные разделы: «Задачи», «Документы», «Мысль дня».
- Основной исполнитель — Китриш О.; постановщики — Радзиевская Т., Лю Ш., Ню Я.
- Юмор строится на серьёзной корпоративной форме и повторяющемся рабочем абсурде.
- Финальная задача существует только последней строкой списка задач и не раскрывается сверху.
- Финальная идея — создать ещё одно хорошее общее воспоминание; формулировка «Проводить Олю» исключена.
- Пакеты Ozon/Wildberries — внутренняя шутка, появляющаяся только после открытия финальной задачи.
- Фото Оли в финале пока не добавляется; пользовательский placeholder также не показывается.
- Финальная сцена строится на контрасте «максимальный абсурд → резкая тишина → искренний текст»; праздничная часть ограничена по времени, а эмоциональный экран остаётся открытым без новых шуток и действий.
- Праздничный финал длится 111 секунд. Сама система Saby визуально «ломается»: меняются статусы и счётчик, а логотип распадается на отдельные буквы с краткой пасхалкой «SABЫ».
- Тайминг финала пересмотрен: сценарий рассчитан на человека, впервые читающего текст, а не на знакомого с содержанием разработчика. Праздничный акт длится 111 секунд; важные фразы удерживаются 4–8 секунд.
- Основные красные счётчики первого экрана зафиксированы как «Задачи: 20 368» и «Документы: 428»; остальные числа не получают такой визуальный акцент.
- После открытия последней задачи финальный сценарий переходит в центральную область: setup — модальное окно до 1040 px, вечеринка — до 1180 px, эмоциональный финал — центрированный viewport.
- Кульминация системного завершения — «Переход в режим «Просто люди»…». После эмоционального финала последней строкой остаётся «Продолжение следует…».
- Фото Оли в обновлённом финале по-прежнему не используется.
- Реальные лица без явной необходимости не изменяются; случайные люди не добавляются.
- Розовая фата и другие спойлеры будущего мероприятия не используются.
- Важен баланс корпоративного юмора и тёплого, но пока несентиментального финала.
- «Мысль дня» независима от финальной задачи.
- Старый набор «Мыслей дня» заменён: из него сохранена только карточка «Красные клопы приходят и уходят. Согласование остаётся.», а основной набор берётся из локальной папки `мысль дня`.
- Карточки показываются без синих кружков и нумерации; готовый текст внутри изображений не дублируется HTML-слоем.
- Состояния хранятся локально в React, а прогресс мыслей — в `localStorage`; backend не нужен.
- До достижения 23/23 кнопка «Другая мысль» выбирает только ещё не просмотренные карточки; завершение обозначается строкой «Освоено: 23 из 23 · Все мудрости просмотрены ✓».
- Сайт не должен становиться полноценной копией рабочего сервиса, собирать данные или требовать входа.
- Публичная mock-строка профиля сохраняет исходную визуальную плотность, но в телефоне изменена одна цифра, а домен e-mail намеренно записан как `baltikpearl.net`; сторонние служебные документы, адреса и реквизиты не публикуются.
- Полный источник фотографии профиля и прежние файлы «Мыслей дня» сохраняются как согласованный контент; CSS продолжает показывать прежний фрагмент фотографии.
- Финальный экран содержит пометку «Неофициальный пародийный проект. Не связан с Saby/СБИС.»
